# Guides

Each guide is one task, start to finish, with the console's own labels. They
assume Syntra is installed and you can open **Administration**. Settings and
background are in [Configure](../configure.md) and [Operate](../operate.md).

| Guide | Time | You need |
|---|---|---|
| [Add SSO to an application from the catalog](sso-from-catalog.md) | 15 min | Admin access to the application |
| [Provision accounts into Active Directory](provision-active-directory.md) | 45 min | A service account with rights on one OU, LDAPS |
| [Switch existing Mattermost users to SAML sign-in](mattermost-saml.md) | 30 min | A Mattermost target, Mattermost Enterprise |
| [Leave one person out of a target](leave-person-out.md) | 5 min | `provision.manage` |
| [Run your first access review](first-access-review.md) | 20 min, plus the review period | People with managers or owners recorded |
| [Back up Syntra and copy backups off the host](backups-off-host.md) | 20 min | The release layout, root on the host |

The times are estimates for a first attempt.
